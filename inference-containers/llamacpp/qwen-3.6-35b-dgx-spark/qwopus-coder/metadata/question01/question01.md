# Linear Algebra Exam Question (MIT 18.06 Inspired — original problem, not a reproduction)

Consider a 3×3 matrix A:

```
A = [ 2  -1   0 ]
    [ -1  2  -1 ]
    [ 0  -1   2 ]
```

### Part (a)
Find all eigenvalues of A. Show your work.

### Part (b)
Find a basis of eigenvectors for each eigenvalue.

### Part (c)
Diagonalize A, i.e., find an invertible matrix P and a diagonal matrix D such that A = P D P⁻¹.

### Part (d)
Using the diagonalization from part (c), compute A¹⁰. Hint: Aⁿ = P Dⁿ P⁻¹.

### Bonus (optional)
This matrix appears in the discretization of the 1D Laplacian operator. Can you explain why the eigenvalues take the form they do? What would the eigenvalues be for an n×n version of this matrix?
