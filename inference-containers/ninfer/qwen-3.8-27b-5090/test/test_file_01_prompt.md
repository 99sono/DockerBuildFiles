# Test Prompt: Complex Logic and Verification

Please solve the following problem step by step:

Consider the function f(n) defined for positive integers n by:
f(1) = 1
f(2n) = f(n)
f(2n+1) = f(2n) + 1

Find the number of integers n in the range [1, 2048] for which f(n) = 5.
Explain the mathematical pattern clearly and double-check your answer.
